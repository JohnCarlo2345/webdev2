## CRUD App Specification - Book Library Manager ##

## Project Description ##
A simple web-based application to manage a personal book library. Users can add new books, view all books, update book details, and remove books from the collection.

## Functional Requirements ##

**REQ-01:** A user can view a complete list of all books in the library.

**REQ-02:** A user can submit a form to add a new book with title, author, publication year, and genre.

**REQ-03:** A user can select an existing book, edit its details, and save the changes.

**REQ-04:** A user can delete a book from the library.
